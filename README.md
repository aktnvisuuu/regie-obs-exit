# Régie EXIT

Télécommande iPhone pour piloter un OBS (local ou cloud IRLToolkit) via obs-websocket v5 :
retour image programme / entrée, scènes, sources, filtres, textes, vumètres et écran de secours.

Ouvrir la page dans Safari puis Partager → « Sur l'écran d'accueil ».
Les réglages (adresse wss://…, mot de passe) restent enregistrés sur le téléphone, jamais dans ce dépôt.
